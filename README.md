# ip

`ip` - библиотека OneScript для строгой работы с IPv4, IPv6, CIDR-префиксами и числовыми
IP-конечными точками. Объекты библиотеки неизменяемы, разбор не выполняет DNS-запросов и других
сетевых операций.

## Требования

- OneScript 2.0.0 или новее;
- OPM для установки зависимостей и сборки пакета.

## Установка

Установите пакет из OPM:

```powershell
opm install ip
```

После установки подключите пакет в сценарии:

```bsl
#Использовать ip
```

Для проекта с файлом `packagedef` добавьте зависимость:

```bsl
Описание.ЗависитОт("ip");
```

## IP-адрес

```bsl
#Использовать ip

Адрес = Новый IPАдрес("2001:0DB8:0:0:0:0:0:1");

Сообщить(Адрес.ВСтроку());
```

Результат:

```text
2001:db8::1
```

## CIDR-префикс

```bsl
#Использовать ip

Адрес = Новый IPАдрес("192.168.1.42");

Сеть = Адрес.Префикс(24);

Если Сеть.Содержит(Новый IPАдрес("192.168.1.100")) Тогда
    Сообщить("В одной сети");
КонецЕсли;
```

[`IPПрефикс`](docs/IPПрефикс.md) хранит только канонический базовый адрес. Поэтому строка
`192.168.1.42/24` отклоняется, а `Адрес.Префикс(24)` обнуляет биты узла и возвращает
`192.168.1.0/24`.

## Зона IPv6

```bsl
#Использовать ip

Адрес = Новый IPАдрес("fe80::1%eth0");

Сообщить(Адрес.Зона());
```

Результат:

```text
eth0
```

Зона хранится буквально и имеет локальный смысл. Она допустима для `fe80::/10` и групповых IPv6-адресов
с неглобальной областью. Библиотека не преобразует её в индекс интерфейса и не выполняет декодирование зоны
из синтаксиса URI.

## IP-конечная точка

```bsl
#Использовать ip

Адрес = Новый IPАдрес("2001:db8::1");

КонечнаяТочка = Новый IPКонечнаяТочка(Адрес, 443);

Сообщить(КонечнаяТочка.ВСтроку());
```

Результат:

```text
[2001:db8::1]:443
```

Конечная точка содержит только числовой IP-адрес и порт от 0 до 65535. Имена узлов,
DNS-разрешение и сокеты в библиотеку не входят.

## Разработка

Установить зависимости для разработки:

```powershell
opm install -l --dev
```

Запустить тесты:

```powershell
oneunit execute --recursive
```

Собрать пакет:

```powershell
opm build .
```
