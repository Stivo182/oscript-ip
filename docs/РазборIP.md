# РазборIP

Модуль предоставляет невыбрасывающий программный интерфейс разбора. Адреса, префиксы и конечные
точки разбираются по правилам строгих конструкторов. Для получения сети из адреса с длиной префикса есть
`ПопытатьсяРазобратьСеть()`, которая обнуляет биты узла.

## Общий контракт

Все функции принимают `Строка`. При успехе функция возвращает соответствующий объект и устанавливает
необязательный параметр `Ошибка`, переданный по ссылке, в `Неопределено`. При синтаксической или предметной
ошибке функция возвращает `Неопределено`, а в `Ошибка` помещает `ИнформацияОбОшибке`. Неверный тип параметра
`Представление` вызывает исключение `argument.invalid_type`.

```bsl
Ошибка = Неопределено;
Адрес = РазборIP.ПопытатьсяРазобратьАдрес("192.0.2.1", Ошибка);
```

Если диагностика не нужна, второй параметр можно не передавать.

## ПопытатьсяРазобратьАдрес

```bsl
Адрес = РазборIP.ПопытатьсяРазобратьАдрес(Представление, Ошибка);
```

Возвращает `IPАдрес`. Правила разбора совпадают со строгим конструктором `IPАдрес`.

## ПопытатьсяРазобратьПрефикс

```bsl
Префикс = РазборIP.ПопытатьсяРазобратьПрефикс(Представление, Ошибка);
```

Возвращает канонический `IPПрефикс`. Адрес с установленными битами узла отклоняется по тем же правилам,
что и строгий конструктор `IPПрефикс`.

## ПопытатьсяРазобратьСеть

```bsl
Сеть = РазборIP.ПопытатьсяРазобратьСеть(Представление, Ошибка);
```

Возвращает канонический `IPПрефикс` и обнуляет биты узла. Например, `10.1.2.3/8` преобразуется в
`10.0.0.0/8`. Остальные правила синтаксиса совпадают со строгим разбором `IPПрефикс`.

## ПопытатьсяРазобратьКонечнуюТочку

```bsl
КонечнаяТочка = РазборIP.ПопытатьсяРазобратьКонечнуюТочку(Представление, Ошибка);
```

Возвращает `IPКонечнаяТочка`. Разбирает только числовой IP-адрес и порт. Имена узлов и DNS-разрешение
не поддерживаются.

Синтаксис адресов соответствует
[RFC 4291 §2.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.2). Запись IPv4-префиксов описана
в [RFC 4632 §3.1](https://www.rfc-editor.org/rfc/rfc4632.html#section-3.1), а IPv6-префиксов - в
[RFC 4291 §2.3](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.3).
