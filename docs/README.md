# Документация API

Документация по публичному API пакета `ip`. Все публичные объекты являются
неизменяемыми и работают только с числовыми IP-значениями без сетевого ввода-вывода.

- [Классы](#классы)

## Классы

- [IPАдрес](IPАдрес.md) - IPv4 или IPv6, необязательная зона, двоичное представление и классификация
- [IPПрефикс](IPПрефикс.md) - строгий канонический CIDR-префикс и операции над диапазоном
- [IPКонечнаяТочка](IPКонечнаяТочка.md) - числовой IP-адрес и порт от 0 до 65535
