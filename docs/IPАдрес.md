# IPАдрес

Неизменяемый объект-значение IPv4 или IPv6 с необязательной строковой зоной IPv6. IPv4 хранится
как 32 бита по [RFC 791 § 3.1](https://www.rfc-editor.org/rfc/rfc791.html#section-3.1), IPv6 - как 128 бит по
[RFC 4291 § 2.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.2). Все методы, которые меняют представление,
возвращают новый объект; исходный адрес не изменяется.

Разбор IPv4 принимает только четыре десятичных октета без знаков, пробелов и ведущих нулей.
IPv6 принимает формы [RFC 4291 § 2.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.2), а `ВСтроку()`
выдаёт каноническую запись по
[RFC 5952 § 4](https://www.rfc-editor.org/rfc/rfc5952.html#section-4). Зона следует модели областей действия
[RFC 4007 § 11](https://www.rfc-editor.org/rfc/rfc4007.html#section-11) и актуальным рекомендациям
[RFC 9844 § 5](https://www.rfc-editor.org/rfc/rfc9844.html#section-5), но хранится буквально и не декодируется как
часть URI.

## Создание

```bsl
Новый IPАдрес(<Значение>)
```

Полная диспетчеризация конструктора:

| `Значение` | Поведение |
| --- | --- |
| `Строка` | Строгий разбор IPv4 либо разбор IPv6 с необязательной зоной |
| [`IPАдрес`](IPАдрес.md) | Создание логически равной неизменяемой копии |
| `ДвоичныеДанные` | 4 байта создают IPv4, 16 байт - IPv6; порядок байтов сетевой |
| `Массив` | 4 или 16 целых октетов от 0 до 255; зона отсутствует |
| `ФиксированныйМассив` | 4 или 16 целых октетов от 0 до 255; зона отсутствует |
| Любой другой тип, включая `Null` и `Неопределено` | `argument.invalid_type` |

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, [`IPАдрес`](IPАдрес.md), `ДвоичныеДанные`, `Массив`, `ФиксированныйМассив` | Представление адреса |

Конструктор возвращает новый [`IPАдрес`](IPАдрес.md) либо вызывает исключение:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Недопустим тип значения или октета |
| `argument.invalid_value` | Октет не является целым числом |
| `argument.out_of_range` | Октет находится вне диапазона от 0 до 255 |
| `ip.invalid_address` | Строка не распознана как IP-адрес |
| `ip.invalid_ipv4` | Нарушена строгая точечно-десятичная форма IPv4 |
| `ip.invalid_ipv6` | Нарушена форма IPv6 по [RFC 4291 § 2.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.2) |
| `ip.invalid_zone` | Зона не соответствует профилю библиотеки или области IPv6-адреса |
| `ip.zone_not_allowed_for_ipv4` | Зона указана у IPv4 |
| `ip.invalid_byte_length` | Передано не 4 и не 16 октетов |

Примеры:

```bsl
IPv4 = Новый IPАдрес("192.0.2.1");
IPv6 = Новый IPАдрес("2001:0DB8::1");
СЗоной = Новый IPАдрес("fe80::1%eth0");
Копия = Новый IPАдрес(IPv6);
```

## Методы

### Версия

```bsl
.Версия()
```

Параметры отсутствуют. Возвращает `Число`: `4` для IPv4 или `6` для IPv6. Ошибок предметной
области и аргументов не вызывает.

### ЭтоIPv4

```bsl
.ЭтоIPv4()
```

Параметры отсутствуют. Возвращает `Булево`: `Истина` только для IPv4. Ошибок предметной области
и аргументов не вызывает.

### ЭтоIPv6

```bsl
.ЭтоIPv6()
```

Параметры отсутствуют. Возвращает `Булево`: `Истина` только для IPv6. Ошибок предметной области
и аргументов не вызывает.

### ДлинаВБитах

```bsl
.ДлинаВБитах()
```

Параметры отсутствуют. Возвращает `Число`: `32` для IPv4 или `128` для IPv6. Ошибок предметной
области и аргументов не вызывает.

### ВСтроку

```bsl
.ВСтроку()
```

Параметры отсутствуют. Возвращает `Строка`: строгую точечно-десятичную запись IPv4 либо
канонический IPv6 по RFC 5952. Для IPv6 с зоной добавляет суффикс `%зона`. Ошибок предметной
области и аргументов не вызывает.

```bsl
Новый IPАдрес("2001:0DB8:0:0::1").ВСтроку(); // "2001:db8::1"
```

### СтрокаБезЗоны

```bsl
.СтрокаБезЗоны()
```

Параметры отсутствуют. Возвращает `Строка`: канонический адрес без суффикса зоны. Ошибок
предметной области и аргументов не вызывает.

### РазвернутаяСтрока

```bsl
.РазвернутаяСтрока()
```

Параметры отсутствуют. Возвращает `Строка`. Для IPv4 результат совпадает с `ВСтроку()`; IPv6
содержит восемь четырёхзначных шестнадцатеричных групп в нижнем регистре без зоны. Ошибок
предметной области и аргументов не вызывает.

### Байты

```bsl
.Байты()
```

Параметры отсутствуют. Возвращает новые `ДвоичныеДанные`: 4 байта для IPv4 или 16 байт для
IPv6 в сетевом порядке. Зона в результат не входит. Ошибок предметной области и аргументов не
вызывает.

```bsl
Исходный = Новый IPАдрес("2001:db8::1");
Восстановленный = Новый IPАдрес(Исходный.Байты());
РавныБиты = Исходный.РавноБезЗоны(Восстановленный); // Истина
```

### Октеты

```bsl
.Октеты()
```

Параметры отсутствуют. Возвращает новый `ФиксированныйМассив` из 4 или 16 чисел от 0 до 255.
Изменить адрес через возвращённую коллекцию нельзя. Ошибок предметной области и аргументов не
вызывает.

### ЕстьЗона

```bsl
.ЕстьЗона()
```

Параметры отсутствуют. Возвращает `Булево`: `Истина`, если у IPv6 задана зона. Для IPv4 всегда
возвращает `Ложь`. Ошибок предметной области и аргументов не вызывает.

### Зона

```bsl
.Зона()
```

Параметры отсутствуют. Возвращает `Строка` или `Неопределено`, если зона отсутствует. Ошибок
предметной области и аргументов не вызывает.

### СЗоной

```bsl
.СЗоной(<Зона>)
```

Возвращает новый [`IPАдрес`](IPАдрес.md) с теми же 128 битами и указанной зоной. Исходный объект не меняется. Зона
допустима для локального для канала или группового адреса неглобальной области.

| Параметр | Тип | Описание |
| --- | --- | --- |
| Зона | `Строка` | Непустая зона без `%`, `[`, `]`, U+0000, CR и LF |

Ошибки: `argument.invalid_type` для нестрокового значения, `ip.invalid_zone` для недопустимой строки или области
IPv6-адреса и `ip.zone_not_allowed_for_ipv4` для IPv4.

### БезЗоны

```bsl
.БезЗоны()
```

Параметры отсутствуют. Возвращает новый [`IPАдрес`](IPАдрес.md) с теми же битами без зоны. Ошибок предметной
области и аргументов не вызывает.

### ЭтоНезаданный

```bsl
.ЭтоНезаданный()
```

Параметры отсутствуют. Возвращает `Булево`: `Истина` для `0.0.0.0` или `::`. Ошибок предметной
области и аргументов не вызывает.

### ЭтоПетлевой

```bsl
.ЭтоПетлевой()
```

Параметры отсутствуют. Возвращает `Булево` для IPv4 `127.0.0.0/8` или IPv6 `::1`. Диапазоны
определены [RFC 1122 § 3.2.1.3](https://www.rfc-editor.org/rfc/rfc1122.html#section-3.2.1.3) и
[RFC 4291 § 2.5.3](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.5.3). Ошибок предметной области и аргументов не
вызывает.

### ЭтоЛокальныйДляКанала

```bsl
.ЭтоЛокальныйДляКанала()
```

Параметры отсутствуют. Возвращает `Булево` для IPv4 `169.254.0.0/16` по
[RFC 3927 § 2.1](https://www.rfc-editor.org/rfc/rfc3927.html#section-2.1) или IPv6 `fe80::/10` по
[RFC 4291 § 2.5.6](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.5.6). Ошибок предметной области и аргументов не
вызывает.

### ЭтоЧастный

```bsl
.ЭтоЧастный()
```

Параметры отсутствуют. Возвращает `Булево` для частных IPv4-диапазонов по
[RFC 1918 § 3](https://www.rfc-editor.org/rfc/rfc1918.html#section-3) или IPv6 `fc00::/7` по
[RFC 4193 § 3.1](https://www.rfc-editor.org/rfc/rfc4193.html#section-3.1). Ошибок предметной области и аргументов не
вызывает. Результат является классификацией, а не гарантией безопасности или маршрутизируемости.

### ЭтоГрупповой

```bsl
.ЭтоГрупповой()
```

Параметры отсутствуют. Возвращает `Булево` для IPv4 `224.0.0.0/4` по
[RFC 1112 § 4](https://www.rfc-editor.org/rfc/rfc1112.html#section-4) или IPv6 `ff00::/8` по
[RFC 4291 § 2.7](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.7). Ошибок предметной области и аргументов не
вызывает.

### ЭтоДляДокументации

```bsl
.ЭтоДляДокументации()
```

Параметры отсутствуют. Возвращает `Булево` для IPv4-диапазонов документации по
[RFC 5737 § 3](https://www.rfc-editor.org/rfc/rfc5737.html#section-3) или IPv6 `2001:db8::/32` по
[RFC 3849 § 2](https://www.rfc-editor.org/rfc/rfc3849.html#section-2). Ошибок предметной области и аргументов не
вызывает.

### ЭтоIPv6СОтображеннымIPv4

```bsl
.ЭтоIPv6СОтображеннымIPv4()
```

Параметры отсутствуют. Возвращает `Булево`: `Истина` для IPv6 из диапазона
`::ffff:0:0/96`, определённого
[RFC 4291 § 2.5.5.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.5.5.2). Для IPv4
возвращает `Ложь`. Ошибок предметной области и аргументов не вызывает.

### IPv6

```bsl
.IPv6()
```

Параметры отсутствуют. Возвращает новый [`IPАдрес`](IPАдрес.md). IPv4 преобразуется в IPv6 с отображённым
IPv4 без зоны; IPv6 копируется с зоной. Ошибок предметной области и аргументов не вызывает.

```bsl
Новый IPАдрес("192.0.2.1").IPv6().ВСтроку(); // "::ffff:192.0.2.1"
```

### IPv4

```bsl
.IPv4()
```

Параметры отсутствуют. Возвращает новый [`IPАдрес`](IPАдрес.md) либо `Неопределено`. IPv4 копируется, из
IPv6 с отображённым IPv4 извлекается IPv4 без зоны, а для остальных IPv6 возвращается
`Неопределено`. Ошибок предметной области и аргументов не вызывает.

### Префикс

```bsl
.Префикс(<ДлинаПрефикса>)
```

Обнуляет биты узла и возвращает новый канонический [IPПрефикс](IPПрефикс.md). Зона исходного
IPv6 не переносится. Модель бесклассового префикса IPv4 соответствует
[RFC 4632 § 3.1](https://www.rfc-editor.org/rfc/rfc4632.html#section-3.1).

| Параметр | Тип | Описание |
| --- | --- | --- |
| ДлинаПрефикса | `Число` | Целое от 0 до 32 для IPv4 или от 0 до 128 для IPv6 |

Возвращаемый тип - [`IPПрефикс`](IPПрефикс.md). Ошибки: `argument.invalid_type`, если передано не число;
`argument.invalid_value`, если число не целое; `argument.out_of_range`, если длина не подходит
семейству адреса.

### Равно

```bsl
.Равно(<Другой>)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другой | [`IPАдрес`](IPАдрес.md) | Сравниваемый адрес |

Возвращает `Булево`. Учитывает семейство, биты, наличие и строку зоны с учётом регистра. Ошибка
`argument.invalid_type` возникает для другого типа.

### РавноБезЗоны

```bsl
.РавноБезЗоны(<Другой>)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другой | [`IPАдрес`](IPАдрес.md) | Сравниваемый адрес |

Возвращает `Булево`, сравнивая только семейство и биты. Ошибка `argument.invalid_type` возникает
для другого типа.

### Сравнить

```bsl
.Сравнить(<Другой>)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другой | [`IPАдрес`](IPАдрес.md) | Сравниваемый адрес |

Возвращает `Число`: `-1`, `0` или `1`. IPv4 меньше IPv6; затем октеты сравниваются
лексикографически в сетевом порядке; при равных битах отсутствие зоны меньше её наличия, а зоны
сравниваются по кодам символов. Это порядок библиотеки, а не порядок маршрутизации. Ошибка
`argument.invalid_type` возникает для другого типа.
