# IPАдрес

Неизменяемый объект-значение IPv4 или IPv6 с необязательной строковой зоной IPv6. IPv4 хранится
как 32 бита по [RFC 791 § 3.1](https://www.rfc-editor.org/rfc/rfc791.html#section-3.1), IPv6 - как 128 бит по
[RFC 4291 § 2.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.2). Все методы, которые меняют представление,
возвращают новый объект; исходный адрес не изменяется.

Разбор IPv4 принимает только четыре десятичных октета без знаков, пробелов и ведущих нулей.
IPv6 принимает формы [RFC 4291 § 2.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.2), а `ВСтроку()`
выдаёт каноническую запись по
[RFC 5952 § 4](https://www.rfc-editor.org/rfc/rfc5952.html#section-4). Зона следует модели областей действия
[RFC 4007 § 11](https://www.rfc-editor.org/rfc/rfc4007.html#section-11) и актуальным рекомендациям
[RFC 9844 § 5](https://www.rfc-editor.org/rfc/rfc9844.html#section-5), но хранится буквально и не декодируется как
часть URI.

## Создание

```bsl
Новый IPАдрес(<Значение>)
```

Полная диспетчеризация конструктора:

| `Значение` | Поведение |
| --- | --- |
| `Строка` | Строгий разбор IPv4 либо разбор IPv6 с необязательной зоной |
| [`IPАдрес`](IPАдрес.md) | Создание логически равной неизменяемой копии |
| `ДвоичныеДанные` | 4 байта создают IPv4, 16 байт - IPv6; порядок байтов сетевой |
| `Массив` | 4 или 16 целых октетов от 0 до 255; зона отсутствует |
| `ФиксированныйМассив` | 4 или 16 целых октетов от 0 до 255; зона отсутствует |
| Любой другой тип, включая `Null` и `Неопределено` | `argument.invalid_type` |

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, `IPАдрес`, `ДвоичныеДанные`, `Массив`, `ФиксированныйМассив` | Представление адреса |

Конструктор возвращает новый [`IPАдрес`](IPАдрес.md) либо вызывает исключение:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Недопустим тип значения или октета |
| `argument.invalid_value` | Октет не является целым числом |
| `argument.out_of_range` | Октет находится вне диапазона от 0 до 255 |
| `ip.invalid_address` | Строка не распознана как IP-адрес |
| `ip.invalid_ipv4` | Нарушена строгая точечно-десятичная форма IPv4 |
| `ip.invalid_ipv6` | Нарушена форма IPv6 по [RFC 4291 § 2.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.2) |
| `ip.invalid_zone` | Зона не соответствует профилю библиотеки или области IPv6-адреса |
| `ip.zone_not_allowed_for_ipv4` | Зона указана у IPv4 |
| `ip.invalid_byte_length` | Передано не 4 и не 16 октетов |

Примеры:

```bsl
IPv4 = Новый IPАдрес("192.0.2.1");
IPv6 = Новый IPАдрес("2001:0DB8::1");
СЗоной = Новый IPАдрес("fe80::1%eth0");
Копия = Новый IPАдрес(IPv6);
```

## Методы

### Версия

Возвращает версию IP-адреса.

```bsl
.Версия()
```

#### Возвращаемое значение

`Число`: `4` для IPv4 или `6` для IPv6.

### ЭтоIPv4

Проверяет, принадлежит ли адрес семейству IPv4.

```bsl
.ЭтоIPv4()
```

#### Возвращаемое значение

`Булево`: `Истина` только для IPv4.

### ЭтоIPv6

Проверяет, принадлежит ли адрес семейству IPv6.

```bsl
.ЭтоIPv6()
```

#### Возвращаемое значение

`Булево`: `Истина` только для IPv6.

### ДлинаВБитах

Возвращает длину IP-адреса в битах.

```bsl
.ДлинаВБитах()
```

#### Возвращаемое значение

`Число`: `32` для IPv4 или `128` для IPv6.

### ВСтроку

Преобразует IP-адрес в каноническую строку.

```bsl
.ВСтроку()
```

#### Возвращаемое значение

`Строка`: строгая точечно-десятичная запись IPv4 либо
каноническая запись IPv6 по RFC 5952. Для IPv6 с зоной добавляется суффикс `%зона`.

#### Пример

```bsl
Новый IPАдрес("2001:0DB8:0:0::1").ВСтроку(); // "2001:db8::1"
```

### ВСтрокуБезЗоны

Преобразует IP-адрес в каноническую строку без зоны IPv6.

```bsl
.ВСтрокуБезЗоны()
```

#### Возвращаемое значение

`Строка`: канонический адрес без суффикса зоны.

### ВРазвернутуюСтроку

Преобразует IP-адрес в развёрнутую строку без сокращения нулевых групп IPv6.

```bsl
.ВРазвернутуюСтроку()
```

#### Возвращаемое значение

`Строка`. Для IPv4 результат совпадает с `ВСтроку()`; IPv6
содержит восемь четырёхзначных шестнадцатеричных групп в нижнем регистре и сохраняет суффикс
`%зона`, если зона задана.

### ДвоичныеДанные

Возвращает двоичное представление IP-адреса.

```bsl
.ДвоичныеДанные()
```

#### Возвращаемое значение

Новые `ДвоичныеДанные`: 4 байта для IPv4 или 16 байт для
IPv6 в сетевом порядке. Зона в результат не входит.

#### Пример

```bsl
Исходный = Новый IPАдрес("2001:db8::1");
Восстановленный = Новый IPАдрес(Исходный.ДвоичныеДанные());
РавныБиты = Исходный.РавноБезУчетаЗоны(Восстановленный); // Истина
```

### Октеты

Возвращает октеты IP-адреса.

```bsl
.Октеты()
```

#### Возвращаемое значение

Новый `ФиксированныйМассив` из 4 или 16 чисел от 0 до 255.
Изменить адрес через возвращённую коллекцию нельзя.

### ИмеетЗону

Проверяет, задана ли у IPv6-адреса зона.

```bsl
.ИмеетЗону()
```

#### Возвращаемое значение

`Булево`: `Истина`, если у IPv6 задана зона. Для IPv4 всегда
возвращает `Ложь`.

### Зона

Возвращает зону IPv6-адреса.

```bsl
.Зона()
```

#### Возвращаемое значение

`Строка` или `Неопределено`, если зона отсутствует.

### КопияСЗоной

Возвращает копию IPv6-адреса с указанной зоной.

```bsl
.КопияСЗоной(<Зона>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Зона | `Строка` | Непустая зона без `%`, `[`, `]`, U+0000, CR и LF |

#### Возвращаемое значение

Новый [`IPАдрес`](IPАдрес.md) с теми же 128 битами и указанной зоной.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано нестроковое значение |
| `ip.invalid_zone` | Зона содержит недопустимые символы или не соответствует области IPv6-адреса |
| `ip.zone_not_allowed_for_ipv4` | Метод вызван для IPv4 |

#### Поведение

Исходный объект не меняется. Зону можно указывать у локального для канала адреса или у группового
адреса неглобальной области.

### КопияБезЗоны

Возвращает копию IP-адреса без зоны.

```bsl
.КопияБезЗоны()
```

#### Возвращаемое значение

Новый [`IPАдрес`](IPАдрес.md) с теми же битами без зоны.

### Следующий

Возвращает следующий адрес того же семейства без зоны. Для максимального IPv4 или IPv6 возвращает
`Неопределено`.

```bsl
Новый IPАдрес("192.0.2.255").Следующий().ВСтроку(); // "192.0.3.0"
```

### Предыдущий

Возвращает предыдущий адрес того же семейства без зоны. Для `0.0.0.0` и `::` возвращает `Неопределено`.

```bsl
Новый IPАдрес("192.0.3.0").Предыдущий().ВСтроку(); // "192.0.2.255"
```

### ЭтоНезаданный

Проверяет, является ли IP-адрес незаданным.

```bsl
.ЭтоНезаданный()
```

#### Возвращаемое значение

`Булево`: `Истина` для `0.0.0.0` или `::`.

### ЭтоПетлевой

Проверяет, является ли IP-адрес петлевым.

```bsl
.ЭтоПетлевой()
```

#### Возвращаемое значение

`Булево` для IPv4 `127.0.0.0/8` или IPv6 `::1`. Диапазоны
определены [RFC 1122 § 3.2.1.3](https://www.rfc-editor.org/rfc/rfc1122.html#section-3.2.1.3) и
[RFC 4291 § 2.5.3](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.5.3).

### ЭтоЛокальныйДляКанала

Проверяет, является ли IP-адрес локальным для канала.

```bsl
.ЭтоЛокальныйДляКанала()
```

#### Возвращаемое значение

`Булево` для IPv4 `169.254.0.0/16` по
[RFC 3927 § 2.1](https://www.rfc-editor.org/rfc/rfc3927.html#section-2.1) или IPv6 `fe80::/10` по
[RFC 4291 § 2.5.6](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.5.6).

### ЭтоЧастный

Проверяет, принадлежит ли IP-адрес частному диапазону.

```bsl
.ЭтоЧастный()
```

#### Возвращаемое значение

`Булево` для частных IPv4-диапазонов по
[RFC 1918 § 3](https://www.rfc-editor.org/rfc/rfc1918.html#section-3) или IPv6 `fc00::/7` по
[RFC 4193 § 3.1](https://www.rfc-editor.org/rfc/rfc4193.html#section-3.1).
Результат является классификацией, а не гарантией безопасности или маршрутизируемости.

### ЭтоГрупповой

Проверяет, является ли IP-адрес групповым.

```bsl
.ЭтоГрупповой()
```

#### Возвращаемое значение

`Булево` для IPv4 `224.0.0.0/4` по
[RFC 1112 § 4](https://www.rfc-editor.org/rfc/rfc1112.html#section-4) или IPv6 `ff00::/8` по
[RFC 4291 § 2.7](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.7).

### ПредназначенДляДокументации

Проверяет, предназначен ли IP-адрес для примеров в документации.

```bsl
.ПредназначенДляДокументации()
```

#### Возвращаемое значение

`Булево` для IPv4-диапазонов документации по
[RFC 5737 § 3](https://www.rfc-editor.org/rfc/rfc5737.html#section-3) или IPv6 `2001:db8::/32` по
[RFC 3849 § 2](https://www.rfc-editor.org/rfc/rfc3849.html#section-2).

Классификаторы петлевых, локальных для канала, частных, групповых, документационных и глобальных одноадресных
адресов анализируют вложенный IPv4 у IPv6-адреса с отображённым IPv4. Семейство, версия и 128-битное
представление адреса при этом не меняются. `ЭтоНезаданный()` является исключением: `::ffff:0.0.0.0` не считается
незаданным IPv6.

### ОбластьГрупповогоАдреса

Возвращает числовую область группового IPv6-адреса по
[RFC 4291 § 2.7](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.7). Для IPv4, IPv6-адреса с отображённым
IPv4 и обычного одноадресного IPv6 возвращает `Неопределено`.

```bsl
.ОбластьГрупповогоАдреса()
```

#### Возвращаемое значение

`Число` от 0 до 15 или `Неопределено`.

### ЭтоIPv6СОтображеннымIPv4

Проверяет, является ли адрес IPv6-адресом с отображённым IPv4.

```bsl
.ЭтоIPv6СОтображеннымIPv4()
```

#### Возвращаемое значение

`Булево`: `Истина` для IPv6 из диапазона
`::ffff:0:0/96`, определённого
[RFC 4291 § 2.5.5.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.5.5.2). Для IPv4
возвращает `Ложь`.

### IPv6

Возвращает представление адреса в семействе IPv6.

```bsl
.IPv6()
```

#### Возвращаемое значение

Новый [`IPАдрес`](IPАдрес.md). IPv4-адрес преобразуется в IPv6-адрес с отображённым
IPv4 без зоны; IPv6-адрес копируется с зоной.

#### Пример

```bsl
Новый IPАдрес("192.0.2.1").IPv6().ВСтроку(); // "::ffff:192.0.2.1"
```

### IPv4

Возвращает представление адреса в семействе IPv4.

```bsl
.IPv4()
```

#### Возвращаемое значение

Новый [`IPАдрес`](IPАдрес.md) либо `Неопределено`. IPv4-адрес копируется, из IPv6-адреса с отображённым
IPv4 извлекается IPv4-адрес без зоны, а для остальных IPv6-адресов возвращается
`Неопределено`.

### СоздатьПрефикс

Создаёт канонический IP-префикс заданной длины.

```bsl
.СоздатьПрефикс(<ДлинаПрефикса>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| ДлинаПрефикса | `Число` | Целое от 0 до 32 для IPv4 или от 0 до 128 для IPv6 |

#### Возвращаемое значение

Новый канонический [`IPПрефикс`](IPПрефикс.md).

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано не число |
| `argument.invalid_value` | Передано нецелое число |
| `argument.out_of_range` | Длина не подходит семейству адреса |

#### Поведение

Метод обнуляет биты узла. Зона исходного IPv6 не переносится. Модель бесклассового IPv4-префикса
соответствует [RFC 4632 § 3.1](https://www.rfc-editor.org/rfc/rfc4632.html#section-3.1).

### Равно

Проверяет равенство IP-адресов с учётом зоны.

```bsl
.Равно(<Другой>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другой | [`IPАдрес`](IPАдрес.md) | Сравниваемый адрес |

#### Возвращаемое значение

`Булево`: `Истина`, если семейство, биты, наличие и строка зоны с учётом регистра совпадают.
Для значения другого типа возвращает `Ложь`.

### РавноБезУчетаЗоны

Проверяет равенство IP-адресов без учёта зоны.

```bsl
.РавноБезУчетаЗоны(<Другой>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другой | [`IPАдрес`](IPАдрес.md) | Сравниваемый адрес |

#### Возвращаемое значение

`Булево`: `Истина`, если семейство и биты адресов совпадают.
Для значения другого типа возвращает `Ложь`.

### Сравнить

Сравнивает IP-адреса в детерминированном порядке библиотеки.

```bsl
.Сравнить(<Другой>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другой | [`IPАдрес`](IPАдрес.md) | Сравниваемый адрес |

#### Возвращаемое значение

`Число`: `-1`, `0` или `1`.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано значение другого типа |

#### Поведение

IPv4 меньше IPv6; затем октеты сравниваются лексикографически в сетевом порядке. При равных битах отсутствие
зоны меньше её наличия, а зоны сравниваются по кодам символов. Это порядок библиотеки, а не порядок маршрутизации.
