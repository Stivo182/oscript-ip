# IPКонечнаяТочка

Неизменяемый объект-значение «числовой [IPАдрес](IPАдрес.md) + порт». Порт является целым числом
от 0 до 65535. Класс не принимает имена узлов, не выполняет DNS-разрешение и не открывает
сокеты. Методы возвращают значения или новые неизменяемые объекты и не меняют конечную точку.

IPv4 основан на 32-битной модели [RFC 791 § 3.1](https://www.rfc-editor.org/rfc/rfc791.html#section-3.1), IPv6 - на
[RFC 4291 § 2.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.2). Каноническая IPv6-часть форматируется по
[RFC 5952 § 4](https://www.rfc-editor.org/rfc/rfc5952.html#section-4), зона сохраняется буквально по модели
[RFC 4007 § 11](https://www.rfc-editor.org/rfc/rfc4007.html#section-11) и
[RFC 9844 § 5](https://www.rfc-editor.org/rfc/rfc9844.html#section-5).

## Создание

```bsl
Новый IPКонечнаяТочка(<Значение>, <Порт> = Неопределено)
```

Полная диспетчеризация конструктора:

| `Значение` | `Порт` | Поведение |
| --- | --- | --- |
| `Строка` конечной точки | `Неопределено` | Разбор `IPv4:порт` или `[IPv6]:порт` |
| [`IPКонечнаяТочка`](IPКонечнаяТочка.md) | `Неопределено` | Создание логически равной неизменяемой копии |
| [`IPАдрес`](IPАдрес.md) | `Число` | Проверка числового порта и создание |
| [`IPАдрес`](IPАдрес.md) | `Неопределено` | `argument.required` для обязательного порта |
| `Строка` IP без скобок | `Число` | Разбор IP-адреса и создание с переданным портом |
| Любая другая комбинация | Любое значение | Ошибка аргумента |

Строка IPv6 в форме конечной точки обязательно заключается в квадратные скобки. При раздельной
передаче адреса и порта строка содержит только IP без скобок.

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, [`IPАдрес`](IPАдрес.md), [`IPКонечнаяТочка`](IPКонечнаяТочка.md) | Исходное значение |
| Порт | `Число`, `Неопределено` | Целое число от 0 до 65535 |

Конструктор возвращает новую [`IPКонечнаяТочка`](IPКонечнаяТочка.md) либо вызывает исключение:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Недопустим тип значения или отдельного порта |
| `argument.required` | Для [`IPАдрес`](IPАдрес.md) не передан порт |
| `argument.out_of_range` | Отдельный порт не является целым числом от 0 до 65535 |
| `ip.invalid_endpoint` | Нарушена строковая структура или адрес имеет неверное семейство для формы |
| `ip.port_out_of_range` | Текстовый порт больше 65535 |

Ошибки разбора отдельной строки IP с числовым портом совпадают с ошибками конструктора
[`IPАдрес`](IPАдрес.md).

```bsl
IPv4 = Новый IPКонечнаяТочка("192.0.2.1:443");
IPv6 = Новый IPКонечнаяТочка("[2001:db8::1]:443");
СЗоной = Новый IPКонечнаяТочка("[fe80::1%eth0]:8080");

Адрес = Новый IPАдрес("2001:db8::1");
ИзОбъекта = Новый IPКонечнаяТочка(Адрес, 443);
ИзСтрокиАдреса = Новый IPКонечнаяТочка("192.0.2.1", 443);
```

В текстовом порте ведущие нули допустимы, но не сохраняются:

```bsl
Новый IPКонечнаяТочка("192.0.2.1:00443").ВСтроку(); // "192.0.2.1:443"
```

## Методы

### Адрес

```bsl
.Адрес()
```

Параметры отсутствуют. Возвращает новый неизменяемый [`IPАдрес`](IPАдрес.md), включая зону IPv6. Изменить
конечную точку через возвращённый объект невозможно. Ошибок предметной области и аргументов не
вызывает.

### Порт

```bsl
.Порт()
```

Параметры отсутствуют. Возвращает `Число`: целое значение от 0 до 65535. Ошибок предметной
области и аргументов не вызывает.

### ВСтроку

```bsl
.ВСтроку()
```

Параметры отсутствуют. Возвращает `Строка`. IPv4 имеет форму `адрес:порт`, IPv6 всегда
заключается в квадратные скобки: `[адрес]:порт`. Зона IPv6 остаётся внутри скобок. Ошибок
предметной области и аргументов не вызывает.

```bsl
Новый IPКонечнаяТочка("[fe80:0:0::1%eth0]:08080").ВСтроку();
// "[fe80::1%eth0]:8080"
```

Повторный разбор результата создаёт равный объект:

```bsl
Исходная = Новый IPКонечнаяТочка("[2001:db8::1]:443");
Копия = Новый IPКонечнаяТочка(Исходная.ВСтроку());
Исходная.Равно(Копия); // Истина
```

### Равно

```bsl
.Равно(<Другая>)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другая | [`IPКонечнаяТочка`](IPКонечнаяТочка.md) | Сравниваемая конечная точка |

Возвращает `Булево`. Адреса сравниваются методом [`IPАдрес.Равно()`](IPАдрес.md#равно), поэтому зона является
частью идентичности; порты также должны совпадать. Ошибка `argument.invalid_type` возникает для
другого типа.

### Сравнить

```bsl
.Сравнить(<Другая>)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другая | [`IPКонечнаяТочка`](IPКонечнаяТочка.md) | Сравниваемая конечная точка |

Возвращает `Число`: `-1`, `0` или `1`. Сначала применяется
[`IPАдрес.Сравнить()`](IPАдрес.md#сравнить), затем порты сравниваются по возрастанию. Порядок
детерминирован библиотекой и не описывает сетевую доступность. Ошибка `argument.invalid_type`
возникает для другого типа.

## Ограничения строкового формата

Не принимаются имена `example.com:443` и `localhost:80`, IPv6 без скобок, отсутствующий порт,
знак порта и значения выше 65535. Класс также не преобразует зону IPv6 в синтаксис URI: правила
URI и сетевого подключения находятся вне его контракта.
