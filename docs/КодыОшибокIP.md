# КодыОшибокIP

Публичный модуль предоставляет стабильные машинные коды предметных ошибок пакета `ip` без
строковых литералов в прикладном коде. Модуль не хранит изменяемого состояния: все функции
чисты, не принимают параметры и возвращают новую строку с постоянным значением.

## Создание и подключение

`КодыОшибокIP` — общий модуль, поэтому конструктора и диспетчеризации аргументов у него нет:

| Сущность | Создание | Использование |
| --- | --- | --- |
| `КодыОшибокIP` | Не создаётся оператором `Новый` | `КодыОшибокIP.<Функция>()` после `#Использовать ip` |

```bsl
#Использовать ip

Код = КодыОшибокIP.НедопустимыйIPv6();
```

## Функции

Каждая функция ниже вызывается без параметров, возвращает `Строка` и не вызывает ошибок
предметной области или аргументов.

### НедопустимыйIPАдрес

```bsl
КодыОшибокIP.НедопустимыйIPАдрес()
```

Возвращает `"ip.invalid_address"`: строка не распознана как IP-адрес.

### НедопустимыйIPv4

```bsl
КодыОшибокIP.НедопустимыйIPv4()
```

Возвращает `"ip.invalid_ipv4"`: нарушена строгая точечно-десятичная запись IPv4 по 32-битной
модели [RFC 791 § 3.1](https://www.rfc-editor.org/rfc/rfc791.html#section-3.1).

### НедопустимыйIPv6

```bsl
КодыОшибокIP.НедопустимыйIPv6()
```

Возвращает `"ip.invalid_ipv6"`: нарушена текстовая форма IPv6 по
[RFC 4291 § 2.2](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.2).

### НедопустимаяЗона

```bsl
КодыОшибокIP.НедопустимаяЗона()
```

Возвращает `"ip.invalid_zone"`: зона IPv6 не соответствует профилю библиотеки или области адреса. Модель зоны
основана на [RFC 4007 § 11](https://www.rfc-editor.org/rfc/rfc4007.html#section-11) и
[RFC 9844 § 5](https://www.rfc-editor.org/rfc/rfc9844.html#section-5).

### ЗонаНедопустимаДляIPv4

```bsl
КодыОшибокIP.ЗонаНедопустимаДляIPv4()
```

Возвращает `"ip.zone_not_allowed_for_ipv4"`: зона передана для IPv4.

### НедопустимаяДлинаБайтов

```bsl
КодыОшибокIP.НедопустимаяДлинаБайтов()
```

Возвращает `"ip.invalid_byte_length"`: двоичное представление или последовательность октетов
содержит не 4 и не 16 элементов.

### НедопустимыйПрефикс

```bsl
КодыОшибокIP.НедопустимыйПрефикс()
```

Возвращает `"ip.invalid_prefix"`: строка не является строгим IP-префиксом в CIDR-форме по
[RFC 4632 § 3.1](https://www.rfc-editor.org/rfc/rfc4632.html#section-3.1) либо содержит запрещённую зону.

### ДлинаПрефиксаВнеДиапазона

```bsl
КодыОшибокIP.ДлинаПрефиксаВнеДиапазона()
```

Возвращает `"ip.prefix_length_out_of_range"`: текстовая длина префикса находится вне диапазона
от 0 до 32 для IPv4 или от 0 до 128 для IPv6.

### УстановленыБитыХоста

```bsl
КодыОшибокIP.УстановленыБитыХоста()
```

Возвращает `"ip.prefix.host_bits_set"`: базовый адрес строгого префикса содержит ненулевые
биты узла.

### НедопустимаяКонечнаяТочка

```bsl
КодыОшибокIP.НедопустимаяКонечнаяТочка()
```

Возвращает `"ip.invalid_endpoint"`: нарушена строковая форма числовой IP-конечной точки.

### ПортВнеДиапазона

```bsl
КодыОшибокIP.ПортВнеДиапазона()
```

Возвращает `"ip.port_out_of_range"`: текстовый порт больше 65535.

### НесовместимыеВерсии

```bsl
КодыОшибокIP.НесовместимыеВерсии()
```

Возвращает `"ip.family_mismatch"`: операция требует одинакового семейства IP-адресов.

## Каталог кодов

| Функция | Значение |
| --- | --- |
| `НедопустимыйIPАдрес()` | `ip.invalid_address` |
| `НедопустимыйIPv4()` | `ip.invalid_ipv4` |
| `НедопустимыйIPv6()` | `ip.invalid_ipv6` |
| `НедопустимаяЗона()` | `ip.invalid_zone` |
| `ЗонаНедопустимаДляIPv4()` | `ip.zone_not_allowed_for_ipv4` |
| `НедопустимаяДлинаБайтов()` | `ip.invalid_byte_length` |
| `НедопустимыйПрефикс()` | `ip.invalid_prefix` |
| `ДлинаПрефиксаВнеДиапазона()` | `ip.prefix_length_out_of_range` |
| `УстановленыБитыХоста()` | `ip.prefix.host_bits_set` |
| `НедопустимаяКонечнаяТочка()` | `ip.invalid_endpoint` |
| `ПортВнеДиапазона()` | `ip.port_out_of_range` |
| `НесовместимыеВерсии()` | `ip.family_mismatch` |

Ошибки неправильных типов и значений аргументов используют стандартные коды зависимости
`errors`, например `argument.invalid_type`, `argument.invalid_value`, `argument.out_of_range` и
`argument.required`; они намеренно не дублируются этим модулем.

## Использование

```bsl
#Использовать errors
#Использовать ip

Попытка
    КонечнаяТочка = Новый IPКонечнаяТочка("[::1]:65536");
Исключение
    Если ДиагностикаОшибок.Содержит(
        ИнформацияОбОшибке(),
        КодыОшибокIP.ПортВнеДиапазона()
    ) Тогда
        Сообщить("Порт вне диапазона");
    КонецЕсли;
КонецПопытки;
```

Для структурированного разбора `ИнформацияОбОшибке` используйте публичные средства пакета
`errors`; этот модуль отвечает только за именование предметных кодов.
