# КодыОшибокIP

Публичный модуль предоставляет стабильные машинные коды предметных ошибок пакета `ip` без
строковых литералов в прикладном коде. Все функции вызываются без параметров и возвращают `Строка`.

## Использование

```bsl
#Использовать errors
#Использовать ip

Попытка
    КонечнаяТочка = Новый IPКонечнаяТочка("[::1]:65536");
Исключение
    Если ДиагностикаОшибок.Содержит(ИнформацияОбОшибке(), КодыОшибокIP.ПортВнеДиапазона()) Тогда
        Сообщить("Порт вне диапазона");
    КонецЕсли;
КонецПопытки;
```

Для структурированного разбора `ИнформацияОбОшибке` используйте публичные средства пакета
`errors`; этот модуль отвечает только за именование предметных кодов.

## Каталог кодов

| Функция | Код | Описание |
| --- | --- | --- |
| `НедопустимыйIPАдрес()` | `ip.invalid_address` | Не распознан IP-адрес |
| `НедопустимыйIPv4()` | `ip.invalid_ipv4` | Неверная запись IPv4 |
| `НедопустимыйIPv6()` | `ip.invalid_ipv6` | Неверная запись IPv6 |
| `НедопустимаяЗона()` | `ip.invalid_zone` | Недопустимая зона IPv6 |
| `ЗонаНедопустимаДляIPv4()` | `ip.zone_not_allowed_for_ipv4` | Зона указана для IPv4 |
| `НедопустимоеКоличествоОктетов()` | `ip.invalid_byte_length` | Не 4 или 16 октетов |
| `НедопустимыйПрефикс()` | `ip.invalid_prefix` | Неверная запись префикса |
| `ДлинаПрефиксаВнеДиапазона()` | `ip.prefix_length_out_of_range` | Длина вне диапазона семейства |
| `УстановленыБитыУзла()` | `ip.prefix.host_bits_set` | Установлены биты узла |
| `НедопустимаяКонечнаяТочка()` | `ip.invalid_endpoint` | Неверная запись конечной точки |
| `ПортВнеДиапазона()` | `ip.port_out_of_range` | Порт больше 65535 |

Ошибки неправильных типов и значений аргументов используют стандартные коды зависимости
`errors`, например `argument.invalid_type`, `argument.invalid_value`, `argument.out_of_range` и
`argument.required`; они намеренно не дублируются этим модулем.
