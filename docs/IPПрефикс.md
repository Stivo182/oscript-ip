# IPПрефикс

Неизменяемый объект-значение канонического IP-префикса. Он хранит семейство, базовый адрес без
зоны и длину префикса; все биты узла базового адреса всегда равны нулю. Операции возвращают
новые [IPАдрес](IPАдрес.md) и не меняют ни префикс, ни переданные объекты.

Бесклассовая модель IPv4 следует
[RFC 4632 § 3.1](https://www.rfc-editor.org/rfc/rfc4632.html#section-3.1). Длина IPv4
находится в диапазоне от 0 до 32, IPv6 - от 0 до 128 в соответствии с архитектурой
[RFC 4291 § 2.3](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.3). Строковое представление адресной части
канонизируется по [RFC 5952 § 4](https://www.rfc-editor.org/rfc/rfc5952.html#section-4).

## Создание

```bsl
Новый IPПрефикс(<Значение>, <ДлинаПрефикса> = Неопределено)
```

Полная диспетчеризация конструктора:

| `Значение` | `ДлинаПрефикса` | Поведение |
| --- | --- | --- |
| `Строка` CIDR | `Неопределено` | Строгий разбор канонической сети |
| [`IPПрефикс`](IPПрефикс.md) | `Неопределено` | Создание логически равной неизменяемой копии |
| [`IPАдрес`](IPАдрес.md) | `Число` | Строгая проверка длины, отсутствия зоны и нулевых битов узла |
| [`IPАдрес`](IPАдрес.md) | `Неопределено` | `argument.required` для `ДлинаПрефикса` |
| Любая другая комбинация | Любое значение | `argument.invalid_type` |

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, [`IPПрефикс`](IPПрефикс.md), [`IPАдрес`](IPАдрес.md) | Представление префикса |
| ДлинаПрефикса | `Число`, `Неопределено` | Длина для конструктора из [`IPАдрес`](IPАдрес.md) |

Конструктор возвращает новый [`IPПрефикс`](IPПрефикс.md) либо вызывает исключение:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Комбинация типов не поддерживается или числовая длина имеет другой тип |
| `argument.required` | Для конструктора из [`IPАдрес`](IPАдрес.md) не передана длина префикса |
| `argument.invalid_value` | Числовая длина не является целой |
| `argument.out_of_range` | Числовая длина для [`IPАдрес`](IPАдрес.md) не подходит семейству |
| `ip.invalid_prefix` | Строка не имеет строгой формы или адресная часть некорректна |
| `ip.prefix_length_out_of_range` | Длина в строке CIDR не подходит семейству |
| `ip.prefix.host_bits_set` | В базовом адресе установлены биты узла |

Если адресная часть некорректна, `ip.invalid_prefix` сохраняет конкретную ошибку конструктора
[`IPАдрес`](IPАдрес.md) в качестве причины. Поля `Компонент` и `Ожидание` уточняют, нарушена ли адресная часть,
длина префикса, зона или структура значения. Границы соответствуют длине адресов и форме префикса из
[RFC 4291, раздел 2.3](https://www.rfc-editor.org/rfc/rfc4291#section-2.3).

Строгий конструктор отклоняет `192.168.1.42/24`. Для удобного маскирования используйте
[`IPАдрес.СоздатьПрефикс()`](IPАдрес.md#создатьпрефикс):

```bsl
Адрес = Новый IPАдрес("192.168.1.42");
Префикс = Адрес.СоздатьПрефикс(24); // 192.168.1.0/24

Строгий = Новый IPПрефикс("2001:db8::/32");
Копия = Новый IPПрефикс(Строгий);
```

## Методы

### Версия

Возвращает версию IP-префикса.

```bsl
.Версия()
```

#### Возвращаемое значение

`Число`: `4` для IPv4 или `6` для IPv6.

### ЭтоIPv4

Проверяет, принадлежит ли префикс семейству IPv4.

```bsl
.ЭтоIPv4()
```

#### Возвращаемое значение

`Булево`: `Истина` только для IPv4-префикса.

### ЭтоIPv6

Проверяет, принадлежит ли префикс семейству IPv6.

```bsl
.ЭтоIPv6()
```

#### Возвращаемое значение

`Булево`: `Истина` только для IPv6-префикса.

### ДлинаАдресаВБитах

Возвращает длину IP-адреса в битах.

```bsl
.ДлинаАдресаВБитах()
```

#### Возвращаемое значение

`Число`: `32` для IPv4 или `128` для IPv6.

### ДлинаПрефикса

Возвращает длину сетевой части префикса в битах.

```bsl
.ДлинаПрефикса()
```

#### Возвращаемое значение

`Число` от 0 до длины адреса в битах.

### БазовыйАдрес

Возвращает базовый адрес префикса.

```bsl
.БазовыйАдрес()
```

#### Возвращаемое значение

Новый [`IPАдрес`](IPАдрес.md) без зоны, в котором все биты узла равны нулю.

#### Поведение

Изменить состояние префикса через возвращённый адрес невозможно.

### Маска

Возвращает битовую маску префикса в виде IP-адреса.

```bsl
.Маска()
```

#### Возвращаемое значение

Новый [`IPАдрес`](IPАдрес.md) с единицами в сетевых битах и нулями в битах узла.

#### Примеры

- Для `192.168.1.0/24` метод возвращает `255.255.255.0`.
- Для IPv6-префикса `/32` метод возвращает `ffff:ffff::`.

### ПервыйАдрес

Возвращает первый адрес диапазона префикса.

```bsl
.ПервыйАдрес()
```

#### Возвращаемое значение

Новый [`IPАдрес`](IPАдрес.md), логически равный `БазовыйАдрес()`.

### ПоследнийАдрес

Возвращает последний адрес диапазона префикса.

```bsl
.ПоследнийАдрес()
```

#### Возвращаемое значение

Новый [`IPАдрес`](IPАдрес.md), у которого все биты узла равны единице.

#### Поведение

Для `192.168.1.0/24` метод возвращает `192.168.1.255`. Для IPv6 метод имеет только битовую семантику
диапазона и не подразумевает широковещательную передачу.

### ВСтроку

Преобразует префикс в каноническую CIDR-строку.

```bsl
.ВСтроку()
```

#### Возвращаемое значение

`Строка` вида `канонический-IP/длина`, например `2001:db8::/32`.

#### Поведение

Зоны в IP-префиксах не допускаются.

### Содержит

Проверяет, входит ли IP-адрес в диапазон префикса.

```bsl
.Содержит(<Адрес>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Адрес | [`IPАдрес`](IPАдрес.md) | Проверяемый адрес |

#### Возвращаемое значение

`Булево`: `Истина`, если адрес входит в диапазон. Для другого семейства возвращает `Ложь`.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано значение другого типа |

#### Поведение

Метод сравнивает первые `ДлинаПрефикса()` бит. Зона адреса игнорируется.

#### Пример

```bsl
Префикс = Новый IPПрефикс("192.168.1.0/24");
Префикс.Содержит(Новый IPАдрес("192.168.1.255")); // Истина
Префикс.Содержит(Новый IPАдрес("192.168.2.1"));   // Ложь
```

### Пересекается

Проверяет, есть ли у двух IP-префиксов общие адреса.

```bsl
.Пересекается(<Другой>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другой | [`IPПрефикс`](IPПрефикс.md) | Сравниваемый префикс |

#### Возвращаемое значение

`Булево`: `Истина`, если у префиксов есть хотя бы один общий адрес. Для разных семейств
возвращает `Ложь`.

#### Ошибки

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Передано значение другого типа |

#### Пример

```bsl
Сеть = Новый IPПрефикс("192.168.0.0/16");
Подсеть = Новый IPПрефикс("192.168.1.0/24");
Сеть.Пересекается(Подсеть); // Истина
```

### СостоитИзОдногоАдреса

Проверяет, состоит ли диапазон префикса из одного IP-адреса.

```bsl
.СостоитИзОдногоАдреса()
```

#### Возвращаемое значение

`Булево`: `Истина` для IPv4 `/32` или IPv6 `/128`.

### Равно

Проверяет равенство IP-префиксов.

```bsl
.Равно(<Другой>)
```

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другой | [`IPПрефикс`](IPПрефикс.md) | Сравниваемый префикс |

#### Возвращаемое значение

`Булево`: `Истина`, если семейства, базовые биты и длины префиксов совпадают.
Для значения другого типа возвращает `Ложь`.

### Сравнить

Сравнивает префиксы сначала по версии адреса, затем по базовым октетам и длине префикса.

```bsl
.Сравнить(<Другой>)
```

Возвращает `-1`, `0` или `1`. Для значения другого типа выбрасывает `argument.invalid_type`.

## Инварианты диапазона

Для любого корректного префикса `ПервыйАдрес()` равен `БазовыйАдрес()`, а оба крайних адреса
принадлежат префиксу. Повторный разбор `ВСтроку()` создаёт равный объект:

```bsl
Префикс = Новый IPПрефикс("2001:db8::/32");
Копия = Новый IPПрефикс(Префикс.ВСтроку());

Префикс.Равно(Копия);                         // Истина
Префикс.Содержит(Префикс.БазовыйАдрес());     // Истина
Префикс.Содержит(Префикс.ПоследнийАдрес());   // Истина
```
