# IPПрефикс

Неизменяемый объект-значение канонического IP-префикса. Он хранит семейство, базовый адрес без
зоны и длину префикса; все биты узла базового адреса всегда равны нулю. Операции возвращают
новые [IPАдрес](IPАдрес.md) и не меняют ни префикс, ни переданные объекты.

Бесклассовая модель IPv4 следует
[RFC 4632 § 3.1](https://www.rfc-editor.org/rfc/rfc4632.html#section-3.1). Длина IPv4
находится в диапазоне от 0 до 32, IPv6 - от 0 до 128 в соответствии с архитектурой
[RFC 4291 § 2.3](https://www.rfc-editor.org/rfc/rfc4291.html#section-2.3). Строковое представление адресной части
канонизируется по [RFC 5952 § 4](https://www.rfc-editor.org/rfc/rfc5952.html#section-4).

## Создание

```bsl
Новый IPПрефикс(<Значение>, <ДлинаПрефикса> = Неопределено)
```

Полная диспетчеризация конструктора:

| `Значение` | `ДлинаПрефикса` | Поведение |
| --- | --- | --- |
| `Строка` CIDR | `Неопределено` | Строгий разбор канонической сети |
| [`IPПрефикс`](IPПрефикс.md) | `Неопределено` | Создание логически равной неизменяемой копии |
| [`IPАдрес`](IPАдрес.md) | `Число` | Строгая проверка длины, отсутствия зоны и нулевых битов узла |
| [`IPАдрес`](IPАдрес.md) | `Неопределено` | `argument.required` для `ДлинаПрефикса` |
| Любая другая комбинация | Любое значение | `argument.invalid_type` |

**Параметры:**

| Имя | Тип | Описание |
| --- | --- | --- |
| Значение | `Строка`, [`IPПрефикс`](IPПрефикс.md), [`IPАдрес`](IPАдрес.md) | Представление префикса |
| ДлинаПрефикса | `Число`, `Неопределено` | Длина для конструктора из [`IPАдрес`](IPАдрес.md) |

Конструктор возвращает новый [`IPПрефикс`](IPПрефикс.md) либо вызывает исключение:

| Код | Условие |
| --- | --- |
| `argument.invalid_type` | Комбинация типов не поддерживается или числовая длина имеет другой тип |
| `argument.required` | Для конструктора из [`IPАдрес`](IPАдрес.md) не передана длина префикса |
| `argument.invalid_value` | Числовая длина не является целой |
| `argument.out_of_range` | Числовая длина для [`IPАдрес`](IPАдрес.md) не подходит семейству |
| `ip.invalid_prefix` | Строка не имеет строгой формы, содержит зону или некорректную длину |
| `ip.prefix_length_out_of_range` | Длина в строке CIDR не подходит семейству |
| `ip.prefix.host_bits_set` | В базовом адресе установлены биты узла |
| Коды конструктора [`IPАдрес`](IPАдрес.md) | Адресная часть строки не является корректным IP-адресом |

Строгий конструктор отклоняет `192.168.1.42/24`. Для удобного маскирования используйте
[`IPАдрес.Префикс()`](IPАдрес.md#префикс):

```bsl
Адрес = Новый IPАдрес("192.168.1.42");
Префикс = Адрес.Префикс(24); // 192.168.1.0/24

Строгий = Новый IPПрефикс("2001:db8::/32");
Копия = Новый IPПрефикс(Строгий);
```

## Методы

### Версия

```bsl
.Версия()
```

Параметры отсутствуют. Возвращает `Число`: `4` для IPv4 или `6` для IPv6. Ошибок предметной
области и аргументов не вызывает.

### ЭтоIPv4

```bsl
.ЭтоIPv4()
```

Параметры отсутствуют. Возвращает `Булево`: `Истина` только для IPv4-префикса. Ошибок
предметной области и аргументов не вызывает.

### ЭтоIPv6

```bsl
.ЭтоIPv6()
```

Параметры отсутствуют. Возвращает `Булево`: `Истина` только для IPv6-префикса. Ошибок
предметной области и аргументов не вызывает.

### ДлинаАдресаВБитах

```bsl
.ДлинаАдресаВБитах()
```

Параметры отсутствуют. Возвращает `Число`: `32` для IPv4 или `128` для IPv6. Ошибок предметной
области и аргументов не вызывает.

### ДлинаПрефикса

```bsl
.ДлинаПрефикса()
```

Параметры отсутствуют. Возвращает `Число` от 0 до длины адреса в битах. Ошибок предметной
области и аргументов не вызывает.

### БазовыйАдрес

```bsl
.БазовыйАдрес()
```

Параметры отсутствуют. Возвращает новый [`IPАдрес`](IPАдрес.md) без зоны, в котором все биты узла равны нулю.
Изменение состояния префикса через результат невозможно. Ошибок предметной области и аргументов
не вызывает.

### Маска

```bsl
.Маска()
```

Параметры отсутствуют. Возвращает новый [`IPАдрес`](IPАдрес.md) с единицами в сетевых битах и нулями в битах
узла. Для `192.168.1.0/24` возвращается `255.255.255.0`, для IPv6 `/32` - `ffff:ffff::`.
Ошибок предметной области и аргументов не вызывает.

### ПервыйАдрес

```bsl
.ПервыйАдрес()
```

Параметры отсутствуют. Возвращает новый [`IPАдрес`](IPАдрес.md), логически равный `БазовыйАдрес()`. Ошибок
предметной области и аргументов не вызывает.

### ПоследнийАдрес

```bsl
.ПоследнийАдрес()
```

Параметры отсутствуют. Возвращает новый [`IPАдрес`](IPАдрес.md), у которого все биты узла равны единице. Для
`192.168.1.0/24` это `192.168.1.255`. Для IPv6 метод имеет только битовую семантику диапазона и
не подразумевает широковещательную передачу. Ошибок предметной области и аргументов не вызывает.

### ВСтроку

```bsl
.ВСтроку()
```

Параметры отсутствуют. Возвращает `Строка` вида `канонический-IP/длина`, например
`2001:db8::/32`. Зоны в префиксах не допускаются. Ошибок предметной области и аргументов не
вызывает.

### Содержит

```bsl
.Содержит(<Адрес>)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| Адрес | [`IPАдрес`](IPАдрес.md) | Проверяемый адрес |

Возвращает `Булево`. Для другого семейства возвращает `Ложь`; иначе сравнивает первые
`ДлинаПрефикса()` бит. Зона адреса игнорируется. Ошибка `argument.invalid_type` возникает для
другого типа.

```bsl
Префикс = Новый IPПрефикс("192.168.1.0/24");
Префикс.Содержит(Новый IPАдрес("192.168.1.255")); // Истина
Префикс.Содержит(Новый IPАдрес("192.168.2.1"));   // Ложь
```

### Пересекается

```bsl
.Пересекается(<Другой>)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другой | [`IPПрефикс`](IPПрефикс.md) | Сравниваемый префикс |

Возвращает `Булево`: `Истина`, если у префиксов есть хотя бы один общий адрес. Для разных
семейств возвращает `Ложь`. Ошибка `argument.invalid_type` возникает для другого типа.

```bsl
Сеть = Новый IPПрефикс("192.168.0.0/16");
Подсеть = Новый IPПрефикс("192.168.1.0/24");
Сеть.Пересекается(Подсеть); // Истина
```

### ЭтоОдинАдрес

```bsl
.ЭтоОдинАдрес()
```

Параметры отсутствуют. Возвращает `Булево`: `Истина` для IPv4 `/32` или IPv6 `/128`. Ошибок
предметной области и аргументов не вызывает.

### Равно

```bsl
.Равно(<Другой>)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| Другой | [`IPПрефикс`](IPПрефикс.md) | Сравниваемый префикс |

Возвращает `Булево`. Равенство требует одинаковых семейства, базовых битов и длины. Ошибка
`argument.invalid_type` возникает для другого типа.

## Инварианты диапазона

Для любого корректного префикса `ПервыйАдрес()` равен `БазовыйАдрес()`, а оба крайних адреса
принадлежат префиксу. Повторный разбор `ВСтроку()` создаёт равный объект:

```bsl
Префикс = Новый IPПрефикс("2001:db8::/32");
Копия = Новый IPПрефикс(Префикс.ВСтроку());

Префикс.Равно(Копия);                         // Истина
Префикс.Содержит(Префикс.БазовыйАдрес());     // Истина
Префикс.Содержит(Префикс.ПоследнийАдрес());   // Истина
```
